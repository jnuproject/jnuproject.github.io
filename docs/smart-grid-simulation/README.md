# 스마트그리드 정전 취약성 시뮬레이션

사진 속 과제 주제인 `정전을 막는 스마트그리드 설계 - 에너지`용 시뮬레이션입니다.

## 실행 방법

브라우저에서 아래 파일을 열면 됩니다.

```bash
open /Users/goyehun/Documents/블록체인/smart-grid-simulation/index.html
```

## 포함된 기능

- IEEE 14-bus 형태의 전력망 데이터
- DC 전력흐름 근사 계산
- N-1 contingency 분석: 송전선 1개씩 제거
- 주제 2 확장 요소: 고장 전파 애니메이션
- 무작위 고장과 표적 공격 비교
- 신재생 발전소 후보 버스별 안정성 비교
- MST 표시
- 결과 CSV 다운로드

## 과제 제출용 문서

- `과제_보고서_초안.md`: 보고서 본문 초안
- `발표_대본.md`: 발표 순서와 말할 내용
- `제출_체크리스트.md`: 제출 전 확인 항목과 예상 질문 답변

## 보고서에 적을 수 있는 설명

이 시뮬레이션은 각 송전선이 고장났을 때 전력망 연결성이 깨지는지, 부하가 얼마나 공급되지 못하는지, 남은 송전선에 과부하가 생기는지를 계산한다. 위험지수는 부하 손실, 과부하, 계통 분리 개수를 함께 반영한다. 고장 전파 애니메이션은 초기 송전선 고장 후 전력흐름을 재계산하고, 이용률이 가장 높은 선로가 다음 단계에서 차단되는 과정을 보여준다. 표적 공격은 N-1 분석에서 가장 위험한 송전선부터 제거하는 방식이고, 신재생 위치 추천은 같은 용량의 태양광/풍력 발전소를 각 버스에 추가한 뒤 전체 N-1 평균 위험이 가장 낮은 위치를 고르는 방식이다.

## 주의

교육용 DC 전력흐름 근사 모델입니다. 실제 계통 운영에는 AC 전력흐름, 무효전력, 전압 안정도, 보호계전기, 발전기 동특성까지 추가로 검토해야 합니다.
